# 2026-09-11

## 出生地改为「省 / 市 / 县」三级联动选择

用户要求：出生地要列出所有城市，可按 省→市→县 选择。

### 实现
- 数据源（合并生成自包含数据集 `mingli-web/src/assets/divisions.json`）：
  - 层级与名称：`element-china-area-data` 的 `regionData`（31 省 → 342 市 → 3056 区县，标准 GB/T 2260）。
  - 经纬度：`yaunfei/GeoJSON_CDN` 的 `all.json`（adcode + lng/lat，覆盖全部行政区划）。
  - 合并方式：按 code 补零对齐 6 位 adcode 关联坐标；坐标自上而下继承（节点缺坐标则用最近祖先），保证 3429 个节点 0 个 null 经度。
    - 校验：天河区 113.3354、东城区 116.4188、乌鲁木齐天山区 87.6201，均正确。
- 前端 `mingli-web/src/views/PaiPan.vue`：
  - 原 `el-select`（37 个城市的扁平下拉）替换为 `el-cascader`，`options=divisions`、`filterable` 可搜索、`clearable`。
  - 新增 `resolveRegion(values)` 按 code 路径定位节点；`onRegionChange` 自动把叶子节点 `longitude` 填入 `form.longitude`（真太阳时校正用），`cityName` 取标签路径并去除直辖市冗余的「市辖区」。
  - 默认出生地 广东省/广州市/天河区；示例快捷按钮改为传 region code 数组。
- 后端无需改动：`/api/bazi/analyze` 仍只收 `longitude`/`cityName`。

### 验证
- Vite 编译 PaiPan.vue 无错（200）；`divisions.json` 经 Vite 正常返回（200）。
- 端到端：经 :5173 代理 POST 新疆乌鲁木齐天山区(87.62°E)→真太阳时 09:54；北京东城区(116.42°E)→05:32，经度正确流入真太阳时。
