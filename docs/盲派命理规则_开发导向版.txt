凡原文标注“待验/不明/有误”或不同讲法并存者，本稿一律以“存疑”标注，不写成确定规则；开发时应保留多种可能而非硬编码单一结论。
本稿仅作传统命理文献的结构化归纳，不构成科学结论或现实预测承诺，不应作为医疗、法律、投资、婚恋等重大决策依据。

2.3 过河拆桥（大财结构）
结构：主位财生宾位官，后由宾位之字制住/坏掉该官（或反向同理）；原局“过河”完成后再处理关键字可能反为得财。
前提：生、制、主宾路径明确；若直接坏功神或改变原局方向，仍可能成反局。
三、官职、学历与行业判定
3.1 官命判定流程
官命核心=官杀+印；官杀主职务，印主权柄，二者须有根。
官杀配印/伤食/劫刃，或印配财/食伤/比禄而做功 → 常有官职；做功最好有主位字参与，否则更偏发财。
官杀虚透偏名气，逢运落实才可能应职。
申酉做功→检法司法；申酉丑寅组合→公安；羊刃配七杀→军警/执法/实权；伤官配官杀→实权/纪检；食神合印→文化性行业。
带帽：官戴财帽以财为主→国企经营/管理财物；财戴官帽以官为主→行政财权；印带官帽=权力。
年上官星被制→国有企业的官；日主合年上官→在国企/大型单位工作（官表单位不表职级）。
3.2 学历判定
学历主要看 官杀 / 印 / 食神；财、伤官、比劫常为破学因素。
官杀要配印，七杀要制化；印要做功；食神主思考。
财多→心乱欲望重；伤官聪明但不喜规训，配印或官杀做功可成学；比劫好动通常不利静学。
文理：金水偏理，木火偏文；庚申戌亥→数学；申子辰→化学；申酉加丑→法律；寅卯配火→中文；食神→中文/外语；官杀→理。
3.3 行业取象
须依共象/合象/化象/墓象/制象综合定，不可只用单一五行。
常用：阴木生火→纺织/服装；阳木生火→家具/装潢；子辰→化工/制药；土木→建筑/房地产；申酉丑→法律/司法；阴阳制化得当→公安/军警。
时柱→门户/门店/车/外部交际；年柱→远方/海外；月令→单位/国家/大机构；主位关系决定本人经营/替人管理/工薪。
四、取象七原则（定象算法）
共象：同一字的干支象、十神象、宫位象（必要时神煞象）有 ≥2 类指向同一事物 → 定象。
合象：两种象经合互相定义，如食神合印→学术/学问，劫财合财→取财方式；仅限原局已有的合。
化象：经生/三合/半合/会合推衍复合象，如阴木生火→纺织/服装，阳木生火→家具/装潢，子辰→化工/制药/提纯。
墓象：墓为收藏/控制，所墓之神定具体义（见墓库表）。
制象：合制/克制/冲制/刑制/穿制形成职业事务复合象；须分清制得住、制不尽、反被制。
带象：一柱干统支，干定支性质。财带官帽=公家之财；官带财帽=管财的官；印带官帽=权力；印/财互带帽=工资/单位收入。
借象：天干与其禄支互借；同五行异阴阳字特定结构互借；须有同根/通禄/带象/宫位关联，不可任意替换。
五、正局与反局判定流程
输入：原局四柱（含日主、日支）、党势、主宾位。
步骤1 定意向：先看日主是否合/生/做功；若日主不做功，转看日支意向。
步骤2 看日支方向：日支所“追求之物”若与原局之势相反 → 反局；不能只看表面冲克。
步骤3 看日主与日支同功：两者同时做功时以日主为主，意同=正局，意反=反局；日主合到某柱时一并看该柱坐支是否同向。
步骤4 看时支：辛日丙申时、丁日壬寅时、己日甲戌时——时支为劫/体，不可坏；时支是用则可坏。
步骤5 冲合反局：年月与日时构成两党且地支一边合一边冲、交叉对立 → 冲合反局；内外分层、主宾一致对外者不为反局；天干合+地支冲本身不直接构成此类反局。
输出：正局 / 原局反局 / 大运反局 / 流年反局 / 冲合反局，并标注反在哪个事项（财/官/婚/身等）。
六、婚姻、子女与桃花
6.1 婚姻判定
以夫妻宫(日支)为主、配偶星为辅：男财为妻，女官杀为夫；男无财看伤食，女无官杀看印。
配偶星在年月→偏早婚，在日时→偏晚婚。
好婚姻：夫妻宫安静，不被刑冲破穿、不被配偶星以外之字合走、少杂透多现；宫能制去星所忌之字或星合入宫且制得住。
差婚姻：宫为用却被刑冲破穿/他合/杂透多现；宫为忌无制；比劫争夫(妻)；宫制星却制不住。破坏轻重→争吵/分居/离异。
正星得正位(男正财/女正官坐宫)通常不喜被制被合；偏星相对可制。
多婚线索：宫穿星、宫或星多现、正星得正位被他合、比劫争配偶再逢宫坏；婚次估算为经验口径，须审慎。
独身常见：日时为比劫/禄/印使配偶难入；宫制星制不住反受星坏；宫为配偶墓且不开；正星得位自合而偏星干扰(水中捞月)。
桃花：禄合财/官杀/伤食、禄逢三合为桃花(禄合印不为桃花)；配偶/异性星在偏位与宫发生关系；男食伤亦可为桃花。是否成婚仍以宫星位置及是否被坏为准。
婚期应期：星经六/三合合入宫；星天干五合到日主；原合绊逢冲解合；星或宫入墓逢刑冲开墓。天干合定婚期时星须有根得旺，虚浮被合可能是制坏非婚。
6.2 子女取法
基本：男命七杀为儿、正官为女；女命伤官为儿、食神为女。须看财/宫位/空亡及岁运变通，不能只按一条。
看子女顺序：日支→时支→时干→月支→月干→年支→年干；墓库逢冲可能主子女数多。
原文提出把子女出生年放入“第五柱”结合原局看其情况。

7.2 应期规则
原身/禄应期：流年或大运出现原局某字、其禄或原身，常为该字应期；见禄代表原身，见原神代表禄。
透干应期：地支藏干透到大运/流年天干，引发该地支信息，如寅借丙/甲，辰借乙/癸。
作用应期：岁运与原局、或流年与大运发生合/冲/刑/穿/墓，作用到哪个字，哪个字事项易发动。
口诀：合主到，冲主动，墓主收，穿主伤。原局有合以冲为应；原局有冲以合为应；旺者逢冲多冲起，弱者被旺冲多冲去。
代表顺序（以某年天干为例）：先地支后天干；地支中先本气，再墓气，最后余气。
岁运反局触发：原局做功明确时，岁运改变原有冲/合/制/穿方向，或扶助原局所要制去的一方 → 反局，主该运/年挫折官非病伤失职；原局无明确制功者不必机械论反。
八、牢狱与违法风险
牢狱象：亥/丑/辰在特定结构可取牢狱；水多金沉；枭神夺食；劫财伤官组合再与官杀对抗；反局兼见辰丑。
犯罪倾向取象：伤官与官杀对抗而非制成，或比劫与伤官结伙、比劫抗杀。
是否应牢狱：还须看官杀出现、岁运引动、原局是否失衡。
出狱取法：日主得禄、日主合出或冲出，或牢狱为库而岁运冲穿开库。
以上为原文经验归纳，不能替代现实法律判断。
